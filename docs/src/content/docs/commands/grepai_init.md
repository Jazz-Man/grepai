## grepai init

Initialize grepai in the current directory

### Synopsis

Initialize grepai by creating a .grepai directory with configuration.

This command will:
- Create .grepai/config.yaml with default settings
- Prompt for the embedding provider (ollama, lmstudio, openai, synthetic,
  openrouter or requesty) and the storage backend (gob, postgres or qdrant)
- Add .grepai/ to .gitignore if present

Use --provider, --model and --backend to skip those prompts, or --yes to
accept the defaults (ollama with nomic-embed-text, gob).

```
grepai init [flags]
```

### Options

```
  -b, --backend string    Storage backend (gob, postgres, or qdrant)
  -h, --help              help for init
      --inherit           Inherit configuration from main worktree (for git worktrees)
  -m, --model string      Embedding model (default depends on the provider: nomic-embed-text for ollama, text-embedding-3-small for openai; openrouter also accepts text-embedding-3-large and qwen3-embedding-8b)
  -p, --provider string   Embedding provider (ollama, lmstudio, openai, synthetic, openrouter, or requesty)
      --ui                Run interactive Bubble Tea UI wizard
      --yes               Use defaults without prompting
```
